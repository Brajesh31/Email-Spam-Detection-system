# Code of Conduct

We want this project to remain respectful, constructive, and welcoming.

Expected behavior:
- Communicate respectfully and assume good intent.
- Give feedback about code and ideas, not personal attributes.
- Respect privacy and never publish private message content or personal information.
- Be open to corrections and differing technical opinions.

Harassment, threats, discrimination, personal attacks, and doxxing are not acceptable. Maintainers may remove contributions or restrict participation when conduct violates these expectations. Report serious incidents privately to the repository owner.
