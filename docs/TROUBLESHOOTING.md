# Troubleshooting

## NLTK stop words are missing

Run:

```bash
python scripts/setup_nltk.py
```

Confirm that the active Python environment is the same one used to launch Flask. The setup script must be able to reach the NLTK download host.

## Model or vectorizer file cannot be loaded

Confirm that both `spam_classifier_model.pkl` and `vectorizer.pkl` exist in the repository root. They must be trusted artifacts generated by compatible versions of the project dependencies. Do not download replacement pickle files from untrusted sources.

## Incompatible scikit-learn or NumPy version

Install the versions in `requirements.txt` in a clean virtual environment. Pickle/joblib artifacts are not a stable cross-version interchange format. If artifacts still fail to load, regenerate both from the notebook using the pinned environment and verify predictions before deployment.

## Notebook cannot find spam.csv

Run Jupyter with the repository root as the working directory, or open the notebook from the repository root. The notebook uses a relative path to `spam.csv`.

## Notebook plotting cell reports an undefined variable

The classification report is built in the notebook cell before plotting. Re-run the notebook from the first cell in a clean kernel so variables are created in order.

## Port 5000 is already in use

Choose another local port:

```bash
# macOS / Linux
PORT=5050 python app.py
```

```powershell
# Windows PowerShell
$env:PORT = "5050"
python app.py
```

## Prediction output seems inconsistent

Confirm that the runtime preprocessing matches the training notebook and that both model artifacts come from the same training run. This project is trained on SMS messages, so performance on email content is not established.

## GitHub Actions fails

Review the workflow log for the failed step. Recreate the pinned Python environment locally, run the compile and unittest commands from the README, and make sure no private message content or generated secrets were committed.
