# Support

## Before asking for help

1. Read the README and relevant documentation in `docs/`.
2. Recreate the environment using the pinned `requirements.txt`.
3. Run `python scripts/setup_nltk.py`.
4. Run the compile and unittest commands in the README.
5. Check the GitHub Actions log if the failure occurs in CI.

## Report a reproducible issue

Use the bug report issue form and include:

- operating system and Python version;
- installation and startup commands;
- expected and actual behaviour;
- sanitized traceback or workflow log;
- whether the issue occurs with the committed model artifacts.

Never include private email/SMS content, credentials, personal identifiers, or confidential data.

## Scope

This project is an educational SMS/text spam-classification demo. Requests for integrations with mail providers, guaranteed phishing detection, enterprise mail filtering, or production service-level commitments are outside the current implementation.
